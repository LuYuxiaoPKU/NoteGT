## 1. 方法

### 1.1 整形规格（Hy4 第 2 轮 + 2026-08 修正）

- **平台型样本**：中间平坦（压平自然衰减），**首尾各段 sin² 等功率淡化**（线性淡化会掉 −3dB 坑）。
- 分音域参数（音乐时间）：F#3 = 60ms 平台 + 8ms 淡化；F#4 = 55ms + ~1 周期(2.7ms)；F#5+ = 55ms + ~1 周期(1.35ms)；F#2/F#1 模型判定 L0 无效。
- 音域归属：`_sources/noteblock-wiki.txt` 乐器表 Range 列（行 221-718）+ 实测 f0 修正（用户自定义样本可能与原版音域不同，见 §3 banjo）。
- 实现细节（`l0shape.py`）：截断到 T_file → 首尾 sin² → 中段包络除法压平（限幅 0.5-2.5×、17 点汉宁缓变）→ 去 DC → 首尾趋零。
- **保留原文件采样率**（用户库 44.1k/48k 混存；不做统一重采样，符合 Hy4 结论 8）。soundfile(libsndfile) 写 OGG，pre-skip 由其管理，回读验证通过（§5）。

### 1.2 验证方法（`verify_l0.py`，RMS 口径，与 Hy4 修正后度量一致）

- 对音高 n（p=2^((n−12)/12)）：播放信号 = 文件 ×p 重采样；以 50ms(1gt) 间隔叠加 K=40 份；
- 指标（稳态中段）：
  - **pp_db**：5ms 汉宁窗 RMS 包络峰峰值；
  - **mod_dbc**：包络 15-30Hz 带内峰值相对载波（对应 20Hz 锯齿）；
  - **perperiod_db**：f0<250Hz 时的逐周期 RMS 起伏（Hy4：低频 20Hz 调制不可测，改看逐周期）。
- 筛选线（两级验收之第一级）：20Hz 调制 ≤ −30dBc 且包络峰峰值 ≤ 3dB。
- 限制：线性重采样（AL 实际为更高阶滤波）；无整轨电平补偿（Hy4：−3~6dB，不影响 pp 与 dBc 的相对值）；K=40 份叠加（远大于 MC 实际并发层）。

## 3. 观察与结论

1. **L0 对 melodic 样本普遍有效**：凡 loopdetect PASS/WARN 的 melodic 样本，60ms 平台整形后 20Hz 锯齿从 −18~−30dBc 降到 −27~−38dBc，pp 从 18-70dB 降到 2-7dB。
2. **F#2 域修正了模型预测**：模型判 F#2(guitar)「L0 无效」，但用户实际 guitar 样本（干净拨弦、快衰减）60ms 整形后 **3.43pp/−38.7dBc，通过筛选线**——**按样本实测，不按音域教条**。trumpet_oxidized(F#2) 反而需要 75ms。→ 结论：**音域参数表是初值，逐样本扫描定参**（工具已支持 `--len-sweep`）。
3. **打击乐（bdrum/snare/click/hat）60ms 平台无效**：pp 仍 9-40dB。原因：打击乐自然衰减在 60ms 内未完成，「压平」把瞬态尾拉平反而与 50ms 间隔错配；短样本（hat 仅 59.6ms 全长）截断后甚至更差（原版 hat 40dB）。→ 打击乐策略待 Hy4 定（第 2 轮问题 4 已问）；**L0 对打击乐的价值只剩并发占用下降**（尾从 ~200ms 降到 60ms）。
4. **dbass 原始 pp=174dB 是样本结构使然**（f0=138.69=1.5×92.5，样本含周期性近静音窗，叠加后出现深谷）；60ms 切片后 9.65pp，仍超线 → 走 L2。
5. **didgeridoo 双线皆败**（L0 12.75pp、L2 −23dBc FAIL）→ 候选：重录/手工循环点；或接受（其乐谱用途待查）。
6. **icechime 用户版显著差于原版**（用户 5.28/−24.2 vs 原版 1.39/−53.7，见 §6）→ 建议该音轨换回原版或重录。
7. **L0 并发收益**（Hy4 结论 11）：60ms 平台 @1gt = 1.2 存活层 vs 原始 ~5 层；247 静态槽下 1gt 密度乐谱（Tetoris 51% 同盒 1gt）的丢音率应可显著下降——**待游戏内实测**（A/B 盲测 + 丢音率）。

## 7. .nbs 乐谱统计（L1 合并 key 可行性，Hy4 问题 6）

结论：
1. **用户乐库两种风格并存**：快板型（Tetoris/Ground's Colour/Touhou9）1gt 同盒重触发率 14-51%，**L1 合并收益极大**（Tetoris 47% 音符可合并、Touhou9 有 96gt 持续音）；和弦/慢板型（用户自己的 WFXLC/珊瑚海/雨爱、Living Millennium 等）1gt 同盒 <2.2%，**L0 重触发锯齿问题很少发生，L1 收益低**。
2. 用户自创和弦谱的主要特征是**同盒 delta>1 再触发**（WFXLC 1069 对/1090 音符）——即同盒隔 N tick 再响，前音尾巴仍在 → 这是 **L2 延音/循环**的目标场景，而非 L1。

## 11. Hy4 第三轮修正（2026-08 答复，全部吸收）

旧 `est_f0` 搜索带 (60, 2000)Hz，**F#1=46.25Hz 被整个排除** → 低频样本退到 2f0。新版 `loopdetect.py` v2：下限 30Hz（`--fmin`）+ 子谐波纠正（检查 f0/2、f0/3 谱峰，输出 `f0Source`）+ `seamFundRatio`（LP 到 1.5×f0 的接缝量，防高频掩盖）+ 淡化升级阈值 3.0→2.0 + render 越界修复（`max(total·SR, a+f+loop+rel)`，不再需要 `--total 12` 绕长起音）。
