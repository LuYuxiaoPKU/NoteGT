## 一句话摘要（给赶时间的）

- 原版发声 = **OpenAL 硬源（source）+ 线性距离衰减**，**没有任何混响/总线处理**；音符盒每个音符独占一个 source，20Hz 重触发就是 20 个 source 叠加。[源码已验证]
- 音符盒：`NOTE_VOLUME=3` → 衰减距离 = max(3,1)×16 = **48 格**，音量增益 = clamp(3,0,1)=1.0（走 RECORDS 分类滑条）；pitch = 2^((note−12)/12)，clamp [0.5,2.0]。[1.21.11 已验证]
- 通道预算：设备 AL source 上限（常见 255）拆成 **静态 247 + 流式 8**，**满了直接丢弃新声音（无抢占）**。[1.21.11 已验证]
- 混响优化模组的正确姿势：**替换样本（包络整形/预混响尾）+ L1 合并 voice + L2 循环延音**，而不是给 OpenAL 加 EFX 总线（原版没有，加 EFX 需自己建设备，成本高）。[源码+Hy4 结论]
